# Telegram Crypto Clicker Bot (Customizable Web3 Mining Game)

This project is a **fully customizable Telegram clicker bot** designed for crypto-themed games. It enables users to earn coins by clicking, start passive mining sessions, and earn referral bonuses — all through a Telegram interface connected to a web game frontend.

---

## 🚀 Features

- 🔘 **/start Command**: Registers users and generates a personal referral link.
- 👆 **Coin Clicking System**: Users can earn coins via a click-based action.
- 🪙 **Passive Mining**: Users can start a 24-hour mining session to generate coins automatically.
- 👥 **Referral System**: Inviting friends gives bonus coins to both parties.
- 📊 **PostgreSQL Integration**: Stores all user data securely.
- 🌐 **Game Frontend Integration**: Connects directly with your web-based clicker game.
- 🔄 **Real-time Updates**: Passive income updates every 5 seconds automatically.
- 🛠️ **Fully Configurable**: Replace links, names, branding, and more for your own coin or game.
